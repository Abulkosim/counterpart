# v0.2.0 (2026-11-13)

One command to set up, one to join.

- **`cpart setup --relay <url>`** creates your identity, starts the daemon in the background and at login, and adds the Counterpart tools to Claude Code and Codex. It checks the relay answers before creating anything, and running it again only does what is missing.
- **`cpart join <invite> <name>`** does the same from an invite. The invite carries the relay's address, so the person invited types nothing else. It waits until the pairing completes and prints the safety code.
- **`cpart invite`** prints the exact line to send.
- **`cpart up`, `cpart down`** start and stop the background daemon. `--boot` installs a systemd user unit on Linux, or a launchd agent on macOS (not yet run on a Mac). One daemon per identity; a second is refused.
- **The daemon starts itself.** `cpart mcp` and `cpart invite` start it if none is running, so an agent session never talks into a queue nobody is emptying.
- **`cpart status`** shows identity, relay, daemon, agents, contacts, and what is waiting for you.
- **Names instead of ids.** A contact's name works wherever a thread id did (`cpart log maya`, `cpart say maya "..."`, `cpart approve maya <id>`), and so do the first characters of an id.
- **`cpart relay --tunnel`** runs a relay on your machine with a public address through cloudflared, for trying it with someone.
- **A relay that stays.** A `Dockerfile` and `docs/relay.md`.
- **`install.sh`** puts `cpart` on your PATH.
- **Checks.** `scripts/setup-smoke.sh` runs in CI. `scripts/two-machines.sh` pairs a host and a container across the public internet and has them sign an agreement.
- **TypeScript 7.**
