# v0.4.0 (unreleased)

Public, installable from npm, and tidied for a reader who has never seen it.

- **Install from npm.** `npm install -g @abulkosim/counterpart` installs `cpart` with no runtime dependencies. The package is bundled to JavaScript by `scripts/build.ts`, because Node does not strip types under `node_modules`. A checkout still runs the TypeScript directly.
- **`install.sh` installs from npm.** Piped into `sh`, it installs the package, under `~/.local` when npm's global folder needs root. Run from a checkout, it puts that checkout on your PATH, as before. Its bin-directory variable is now `CPART_BIN_DIR` (was `CPART_BIN`).
- **The relay image is built from the packed package**, the same files npm installs.
- **Messages that say what to do next.** Usage lines name the proposal id, not a hash. Empty and not-found results name the command that helps. A queued message tells the agent the human starts the daemon with `cpart up`. A stopped viewer says to run `cpart view` again for a new link. `cpart say` and `cpart open --say` say whether the message reached the relay, with the short thread ref, instead of "Queued <id>". After pairing on a machine without Claude Code or Codex, the hint says neither was found on PATH. `cpart --help` fits in 80 columns.
- **Docs rewritten for a public reader.** A shorter README, an index of pages in [docs/README.md](../docs/README.md), and a [SECURITY.md](../SECURITY.md) that says how to report a problem. Each fact has one home. Figures that no recorded run backs were removed.
- **`cpart --version`** (or `-v`) prints the version. The MCP server and the Claude Code plugin report the same version, read from `package.json`; both said 0.2.0 before.
- **A daemon start no longer loses to a look.** Checking whether a daemon runs takes its lock for a moment, and a daemon starting at that moment gave up, so `cpart join` or `cpart up` could say "the daemon did not start" under load. A start now waits out a brief hold.
- **Code tidied.** Comments that narrated history or repeated the code are gone, unused exports are private or removed, and every script says at the top what it needs and what it costs. No behaviour changed beyond the messages and fixes above.
