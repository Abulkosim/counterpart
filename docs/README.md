# Docs

Start with the [README](../README.md) to set up and pair. Each page below is the one place its subject is described.

**How it works**

- [design.md](design.md): what Counterpart is, the principles, the defences against prompt injection, and what is not built.
- [protocol.md](protocol.md): the exact formats and the rules a daemon and a relay enforce.

**Using it**

- [pairing.md](pairing.md): pairing with a short code, and why the relay cannot cheat.
- [relay.md](relay.md): running a relay on your machine, behind a tunnel, or in a container.
- [connectivity.md](connectivity.md): several relays, moving relays, reconnecting, and a Mac with a dev container.
- [mcp.md](mcp.md): what Claude Code and Codex get: the tools, the hooks, and what a session sees.
- [front-desk.md](front-desk.md): letting a tool-less model answer a contact from your repository.
- [guard.md](guard.md): the outbound guard that holds secrets before they leave, and what it misses.
- [verify.md](verify.md): checking in CI that a repository carries what two people signed.

**Evidence**

- [verification.md](verification.md): every run so far, with results and what was not checked. Known limits are at the end.
- [gauntlet.md](gauntlet.md): 144 attacks on the code and how each ended. Generated by `pnpm gauntlet`; the model runs are in [gauntlet-model.json](gauntlet-model.json).
- [redteam.md](redteam.md): trying to talk a tool-using agent into leaking a secret.
- [prior-art.md](prior-art.md): what existed already, and what we took from it.

To report a security problem, see [SECURITY.md](../SECURITY.md).
